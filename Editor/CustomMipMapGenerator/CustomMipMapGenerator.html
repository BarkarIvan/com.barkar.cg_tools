Custom MipMap Generator

GPU-only mip generation for Unity textures with custom filtering, Toksvig support for normals, and single-file or variant outputs.

Overview

Entry Points

  • Editor window: CustomMipMapGeneratorWindow.cs
  • Compute shader: CustomMipMapGenerator.compute

Core Behavior

  • GPU-only pipeline, no CPU fallback.
  • Mips are generated in compute and read back via AsyncGPUReadback.
  • Output is a Texture2D asset with custom mip chain.

Quick Start

  1. Open: Tools - Custom MipMap Generator - Open Window.
  2. Assign the source texture.
  3. Select Texture Type (Color, Normal Map, Data Map).
  4. Adjust filter and sharpening settings.
  5. Select Output Mode (Single File or Variants).
  6. Single File: Generate Custom Mip File (.cmips).
  7. Variants: Generate Standalone or Both Variants.

Single file uses the importer to compress per build target.

Texture Types

Color

  • sRGB workflow; gamma correction is applied in Gamma color space.
  • Edge-aware filtering is available.

Normal Map

  • Normals are renormalized every mip.
  • Optional Toksvig in alpha (Toksvig In Alpha).
  • Output is raw RGB normals. Use tex.rgb * 2 - 1 in shader.

Data Map

  • Linear data, no sRGB/gamma correction.
  • Alpha Filter Mode is hidden; use per-channel filters instead.
  • PreserveCoverage can be applied per-channel and uses the Alpha Clip threshold.
  • For mask-like channels, use per-channel PreserveCoverage.

Per-Channel Filters

  • Average: weighted filter.
  • Min/Max: choose extreme in kernel.
  • Linear Roughness: sqrt(mean(r^2)).
  • Linear Smoothness: 1 - sqrt(mean((1 - s)^2)).
  • Power Mean: (mean(x^p))^(1/p), p < 1 biases dark, p > 1 biases bright.
  • PreserveCoverage: scale channel to keep coverage at Alpha Clip.
  • Metallic tip: Average for blends, Power Mean (p > 1) or Max to keep metal specks.

Filtering and Sharpening

  • Filter Mode: Kaiser (sharper) or EWA (smoother).
  • Edge-aware option affects Color and Data maps only.
  • Sharpen can be applied to the first N mips.

Alpha Filtering

  • None, PreserveCoverage, or MaxFilter.
  • If Toksvig is active, alpha filtering is forced to None.

Sampling Settings

  • Wrap U/V, Sampler Filter, Aniso Level, and Mip Bias are applied to the output texture.
  • For .cmips, these settings are stored on the importer and can be adjusted later.
  • For variant assets, settings are baked into the asset at generation time.

Full-Res Mips and Max Full-Res Ratio

  • Full-Res Mips controls how many early mips sample the full source.
  • Max Full-Res Ratio is a safety cap. If source/dest ratio is too large, the generator switches to the previous mip to avoid GPU timeouts.
  • Typical stable values: Full-Res Mips = 2-3, Max Full-Res Ratio = 8-16.

Single File (.cmips)

One file in Assets that contains the full mip chain.

  • Importer compresses per active build target (mobile/standalone).
  • No build swap needed.
  • Compression settings are stored on the importer and can be adjusted later.

Switch build target to force reimport with the other compression format.

Auto-Generate from PNG (Profiles)

Create a Profile Set asset and the importer will generate .cmips automatically from matching PNG files.

  1. Create a profile set: Tools - Custom MipMap Generator - Create Profile Set.
  2. Assign suffix rules (e.g. _BaseColor, _Normal, _ARM).
  3. Import PNG files with those suffixes to auto-generate *.cmips.

Generation settings live on the Profile Set. Compression and sampling live on the .cmips importer.

Use Tools - Custom MipMap Generator - Regenerate CMips From Profiles after changing profile settings.

Platform Variants

Legacy workflow that stores separate assets per platform (manual selection, no automatic swap).

  • Standalone: *.standalone.asset
  • Mobile: *.mobile.asset

Toksvig Notes

  • Alpha stores |Na| for each mip.
  • Compression must keep alpha (ASTC RGBA, BC7, or RGBA formats).
  • Alpha filtering is disabled while Toksvig is enabled.

Troubleshooting

Black Mips or GPU Timeouts

  • Reduce Full-Res Mips or lower Max Full-Res Ratio.
  • Lower Kaiser radius or switch to EWA.

ASTC Looks Black in Editor

  • Desktop GPUs often do not support ASTC decoding.
  • Switch build target to Standalone to preview BC formats.

Material Lost Reference

  • Assets are updated in place to keep GUIDs intact.
  • If you delete the referenced variant, references will break.
